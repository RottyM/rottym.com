# RottyM enterprise logos

For the "Previously engineered systems for" section on rottym.com (dark background).

## Files
- `disney.svg`, `fema.svg`, `bae-systems.svg`, `faa.svg`, `leidos.svg`, `usa-today.svg` — official logo files (SVG) from Wikimedia Commons, standard colors.
- `*-white.svg` — same logos recolored white for the dark site background. (USA Today keeps its blue circle.)

## Use the white versions on the homepage
The standard-color versions are dark (Disney wordmark is near-black, FEMA is dark blue, USA Today text is dark) and would disappear on the site's dark navy background. The `*-white.svg` set is made for that section. All are SVG, so they scale cleanly at any size.
